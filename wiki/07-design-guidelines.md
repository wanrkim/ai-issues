# 07. 디자인 지침

토스증권 앱의 "실시간 이슈" 화면과 같은 구조를 따른다. 모바일을 먼저 맞추고 데스크톱에서는 폭만 제한한다.

## 간격 규칙

여백, 간격, 요소 크기는 모두 4의 배수로 쓴다. 4, 8, 12, 16, 20, 24, 40, 48을 쓴다.

선 굵기는 예외이다. 구분선은 1px이다. 이는 여백이 아니라 획의 두께이다.

## 토큰

색과 치수는 `web/index.html`의 `:root`에 CSS 변수로 정의한다. 값을 직접 쓰지 않는다.

### 배경

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--bg-top` | `#E8F0FD` | 문서 뿌리, body, 위쪽 고정 영역의 그라데이션 시작 |
| `--bg-soft` | `#F2F6FC` | 고정 영역 그라데이션의 끝이자 목록 위쪽 그라데이션의 시작 |
| `--bg` | `#F4F6F9` | 예비. 현재 화면에서는 쓰지 않는다 |
| `--card` | `#FFFFFF` | 목록이 놓이는 바탕 |

### 글자

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--text` | `#191F28` | 제목, 카드 제목, 선택한 탭 |
| `--text-sub` | `#8B95A1` | 부제 |
| `--text-dim` | `#B0B8C1` | 축 라벨, 출처 수, 갱신 시각, 선택하지 않은 탭 |

### 강조

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--accent` | `#3182F6` | 눈썹 문구 |
| `--up` | `#F04452` | 순위 상승 삼각형 |
| `--down` | `#3182F6` | 순위 하락 삼각형 |

순위가 오르면 빨강, 내리면 파랑이다. 한국의 증권 화면 관행을 따른다.

### 배지

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--badge-hot-bg` / `--badge-hot-fg` | `#FEECEE` / `#F04452` | 급상승 |
| `--badge-new-bg` / `--badge-new-fg` | `#EDF3FE` / `#3182F6` | 새로 진입 |

### 선과 면

| 변수 | 값 | 쓰는 곳 |
|---|---|---|
| `--line` | `#F0F2F5` | 목록 항목 사이의 구분선, 출처 목록의 구분선 |
| `--chip-bg` | `#EDF0F3` | 축 라벨 배경 |

### 치수

| 변수 | 값 | 설명 |
|---|---|---|
| `--gutter` | `20px` | 좌우 여백 |

목록은 흰 바탕 위에 항목을 두고 항목 사이를 `--line` 굵기 1px 선으로 나눈다. 항목마다 배경, 모서리, 그림자를 주지 않는다. 그 세 가지가 세로 공간을 많이 차지하고, 한 화면에 들어가는 항목 수를 줄이기 때문이다. 항목의 위아래 여백은 16px이다.

## 글꼴

기기에 있는 글꼴을 쓴다. 외부에서 불러오지 않는다.

```
-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", Pretendard,
"Malgun Gothic", system-ui, sans-serif
```

| 대상 | 크기 | 굵기 |
|---|---|---|
| 제목 | 24px (접히면 `scale(.7)`) | 800 |
| 눈썹 문구 | 15px | 700 |
| 분류 선택 | 14px | 700 |
| 항목 제목 | 17px | 700 |
| 항목 부제 (펼쳤을 때) | 15px | 400 |
| 순위 숫자 | 17px | 700 |
| 출처 수, 갱신 시각 | 13px | 500 |
| 축 라벨, 배지 | 11px | 600 / 700 |

한국어 제목에는 자간을 `-0.3px`에서 `-0.5px` 사이로 좁힌다.

## 안티패턴

지키지 않으면 실제로 문제가 생겼던 것들이다.

1. **색 값을 직접 쓰지 않는다.** 모두 CSS 변수로 정의하고 참조한다.
2. **여백과 간격에 4의 배수가 아닌 값을 쓰지 않는다.** 선 굵기만 예외이다.
3. **애니메이션에 `font-size`, `width`, `height`를 쓰지 않는다.** 매 프레임 레이아웃을 다시 계산해서 끊긴다. `transform`과 `opacity`만 쓴다.
4. **`filter: drop-shadow`를 카드마다 걸지 않는다.** 요소마다 별도 레이어를 만들고 스크롤할 때마다 다시 그린다. `box-shadow`를 쓴다.
5. **`position: fixed`인 배경 요소를 두지 않는다.** 스크롤할 때마다 다시 그려진다. 배경은 그 색이 필요한 요소가 직접 갖는다.
6. **`contain`과 `content-visibility`를 함부로 쓰지 않는다.** 페인트 가둠이 카드 그림자를 경계에서 잘라낸다.
7. **`scrollIntoView`를 쓰지 않는다.** 스크롤 가능한 상위 요소를 모두 스크롤해서 문서까지 움직인다. 필요한 요소의 `scrollLeft`나 `scrollTop`을 직접 옮긴다.
8. **가로 이동을 터치 이벤트로 직접 구현하지 않는다.** CSS 스크롤 스냅에 맡긴다. 직접 만들면 기기의 관성 및 손가락 추종과 어긋난다.
9. **`resize`에 매번 반응하지 않는다.** iOS는 주소 표시줄이 접히고 펴질 때마다 보낸다. 가로 폭이 실제로 바뀔 때만 처리한다.
10. **위쪽 고정 영역의 배경을 뒤가 비치게 두지 않는다.** 스크롤 위치에 따라 뒤 색이 달라져서 경계가 드러난다. 불투명한 자기 색을 갖게 한다.
11. **문서 스크롤을 막지 않는다.** 사파리가 하단 도구 막대를 접지 않아 목록이 그 위에서 끊긴다.

## 반응형

- 최대 폭 560px. 그보다 넓은 화면에서는 가운데 정렬하고 폭을 제한한다.
- 항목에는 제목만 둔다. 부제는 펼쳤을 때만 보여준다. 한 화면에 들어가는 항목 수를 늘리기 위해서다.
- 노치와 홈 인디케이터 영역은 `env(safe-area-inset-*)`로 처리한다.
