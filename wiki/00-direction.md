# 00. 방향성

## 가치 우선순위

우선순위가 높은 순서대로 적는다. 아래 순서가 충돌할 때는 위에 있는 항목을 따른다.

1. **순위 정확도.** 첫 화면 상위 5개가 "그럴 만하다"고 느껴져야 한다. 이 조건을 만족하지 못하면 나머지 기능은 의미가 없다.
2. **최신성.** 글이 발행된 시점부터 서비스가 감지하는 시점까지의 시간을 줄인다. POC에서는 검증 대상으로 삼지 않는다.
3. **비용.** POC는 월 0원으로 운영한다.
4. **정확성.** 요약 문구의 정확도는 위 세 항목보다 뒤에 둔다.

## 대상 사용자

AI에 관심이 있는 모든 사람을 대상으로 한다. 특정 성별과 연령대로 한정하지 않는다.

## 제품 결정

아래 항목은 확정한 결정이다.

- 메인 화면은 하나이다. 종합 순위만 표시하고, 축별 탭은 두지 않는다.
- 축은 4개이다. 항목마다 축 라벨을 작게 표시한다.

| 축 키 | 이름 | 범위 |
|---|---|---|
| `llm` | LLM/서비스 | Claude, GPT, Gemini, Grok, 코딩 도구 등 모델과 제품 출시 |
| `media` | 영상/이미지 | 영상 생성 모델, 이미지 생성 모델 |
| `hardware` | 하드웨어 | GPU, HBM, 뉴로모픽 등 반도체와 디바이스 |
| `capital` | 기업/자본 | IPO, 투자 유치, 인수, 규제 |

- 사용자는 축을 제외할 수 있다. 기본값은 4개 축을 모두 켠 상태이다. 제외 상태는 브라우저 로컬 저장소에 보관한다.
- 정렬은 2개이다. 인기순이 기본값이고, 최신순을 선택할 수 있다.
- 알림, 회원가입, 결제는 POC 범위 밖이다.
- 화면 문구와 이슈 요약은 한국어로 작성한다.
