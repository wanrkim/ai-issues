# 09. 백로그

아직 시작하지 않은 작업만 적는다. 시작한 작업은 이 페이지에서 지우고, 완료하면 [10-worklog.md](10-worklog.md)에 기록한다.

## B-001. 최신성 개선

GitHub Actions 예약 실행의 지연을 없애기 위해 실행 환경을 Cloudflare Workers로 옮긴다. Workers는 분 단위 cron을 지원하고 유휴 상태에서 잠들지 않는다. 무료 한도의 하위 요청 수 제한 때문에 월 5달러 유료 요금제가 현실적이다.

## B-002. X(트위터) 출처 추가

X API 종량제로 폴링한다. X에서만 먼저 나오는 속보를 놓치는 빈도가 문제가 될 때 착수한다.

## B-003. 한국어 출처 추가

네이버 뉴스 검색 API를 사용한다. 무료 한도는 하루 25,000건이다.

## B-004. 푸시 알림

기본 알림 기준을 정하지 않았다. 임팩트 5만 보낼지 여부를 결정해야 한다.

## B-005. 회원가입과 결제

웹 월 자동결제는 토스페이먼츠 빌링을 사용한다. 사업자등록과 통신판매업 신고가 선행 조건이다. 3일 무료체험에서 카드를 먼저 등록받을지 여부는 나중에 결정한다.

## B-009. Gemini 결제 계정 복구

AI Studio에 선불 크레딧이 있지만 결제 계정이 비활성 상태여서 Gemini API에 연결되지 않는다. 복구하면 무료 등급의 RPD 20 제한이 풀리고 실행 주기를 2시간에서 더 줄일 수 있다. Google Cloud Console에서 결제 계정 상태를 확인해야 한다.

## B-007. Pages 진입 URL 단축

현재 진입 URL은 `https://<사용자명>.github.io/ai-issues/web/`이다. 루트 URL로 열리게 하려면 저장소 루트에 리다이렉트용 `index.html`을 두거나 Actions 기반 Pages 배포로 바꾼다. POC 운영에 지장이 없으므로 뒤로 미룬다.

## B-008. 실행 결과 파일의 커밋 방식

`data/items.json`은 한 번 실행에 약 250KB이고 내용이 매번 바뀐다. 15분 주기로 커밋하면 하루 96개의 커밋이 쌓이고 저장소가 계속 커진다. GitHub Actions 캐시로 옮기거나, 별도 브랜치에 저장하는 방법을 검토한다. Phase 4에서 실제 증가량을 측정한 뒤 결정한다.
